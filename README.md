### 　作品集　·　Selected Works

<img src="src/img/ep1-hyosei.png" width="100%" alt="Episode 1 — Hyōsei" />

A platform for running academic fairs and expos end to end: role-based access, project
submissions, judging panels, live metrics and Excel/PDF export. The backend runs on a
hexagonal architecture with TypeORM, Zod validation, JWT + HttpOnly cookies and rate limiting.

**`TypeScript`** **`Express`** **`PostgreSQL`** **`TypeORM`** &nbsp;·&nbsp;
[**backend**](https://github.com/IgnacioBarraza/hyosei_backend) &nbsp;·&nbsp;
[**frontend**](https://github.com/IgnacioBarraza/Hyosei)

<br />

<img src="src/img/ep2-kobun.png" width="100%" alt="Episode 2 — Kōbun" />

Themed UI, page-range selection, and a proper Windows installer.

**`Python`** **`Tkinter`** **`PyPDF2`** **`Inno Setup`** &nbsp;·&nbsp;
[**repo**](https://github.com/IgnacioBarraza/kobun)
